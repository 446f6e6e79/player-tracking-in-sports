\section{Introduction}\label{sec:intro}
Vision-based tracking provides a scalable alternative to expensive sports analytics hardware, but basketball's rapid movements, mutual occlusions, motion blur, and specular floor reflections pose severe challenges. 

To address these challenges, modern pipelines have largely abandoned classical background subtraction \cite{survey} in favor of tracking-by-detection paradigms. 
Real-time localization is typically driven by single-stage detectors like the YOLO family \cite{yolo_paper}. 
To link these spatial detections temporally, SORT \cite{sort} established a baseline using Kalman filtering, which was later improved to handle 
severe occlusions using deep appearance embeddings (DeepSORT \cite{deepsort,reid}) and low-confidence secondary associations (ByteTrack \cite{bytetrack}). 
Finally, multi-camera configurations \cite{survey} resolve remaining overlaps by applying epipolar geometry and triangulation to lift 2D sequences into 3D space.

Building on these foundations, we present an end-to-end pipeline for multi-view player tracking and 3D reconstruction.
We systematically evaluate these strategies, demonstrating that a domain-adapted YOLO26 with class-agnostic NMS \cite{nms} combined with appearance-based DeepSORT heavily outperforms classical baselines in reducing identity switches. 
Finally, we reconstruct 3D trajectories across three calibrated cameras using SVD-based triangulation, utilizing Kalman smoothing to suppress detection noise.
