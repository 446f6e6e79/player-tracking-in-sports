\section{3D Reconstruction}\label{sec:reconstruction}

\subsection{Camera Calibration}
Intrinsic parameters (focal length, principal point, and radial distortion
coefficients) are provided directly for each camera.
Extrinsic parameters are estimated by solving the Perspective-n-Point (PnP) problem:
a set of court landmarks is manually selected on the first frame of each video, and
their 2D image coordinates are paired with known 3D positions in the court
coordinate system.
Lens distortion is modelled within the PnP solver, so the image does not need to be
pre-undistorted.

\subsection{Rectification}
Before triangulation, the tracked 2D bounding boxes are undistorted using the
estimated intrinsics, mapping each detection into a common, distortion-free
coordinate system.
The reference pixel used for geometry is class-aware: for the ball, the bounding-box
centre is used; for players, the bottom-centre of the box is used, as it
approximates the ground-contact point and allows placement on the court floor plane.

\subsection{Triangulation}
Detections are grouped by identity label and frame index across the three cameras.
Players and the ball are handled by different strategies.

\textbf{Players} are assumed to stand on the court floor ($Z=0$).
For each camera, the reference bottom-centre pixel is back-projected to a 3D ray and
intersected with the ground plane; the resulting per-camera ground estimates are
combined by median-inlier averaging, so the 3D position can be recovered even when
only a single camera observes a player.

\textbf{The ball} is not constrained to the floor. The projection matrices
$P_i = K_i [R_i \mid t_i]$ for all cameras observing the ball in a given frame are
stacked into a linear system
\begin{equation}
  \mathbf{x}_i \times P_i\,\mathbf{X} = \mathbf{0},
\end{equation}
which is solved for the homogeneous 3D point $\mathbf{X}$ via SVD (Direct Linear
Transform, DLT).
Views whose back-projected reprojection error exceeds a threshold are discarded
before a final solve to suppress the influence of erroneous detections.

\subsection{Trajectory Smoothing}
The raw triangulated trajectories contain noise from detection jitter, calibration
imprecision, and occasional outliers.
Per-entity, a Kalman filter with state vector $[\mathbf{p}, \dot{\mathbf{p}}]$
(position and velocity) is run forward over the trajectory, followed by an
RTS (Rauch--Tung--Striebel) backward smoother, so each point is corrected using
both past and future observations.
Measurements whose Mahalanobis distance exceeds a chi-square gate are rejected as
outliers, and trajectories are split wherever the gap between consecutive
observations exceeds a maximum length to avoid extrapolation over long occlusions.
