% ----- Prior work ----------------------------------------------
\begin{frame}{Tracking: Prior Work and Limitations}
\begin{itemize}
  \item \textbf{SORT} \cite{sort} (tracking by detection): 
  \begin{itemize}
    \item Kalman filter with a constant-velocity motion model.
    \item Hungarian assignment on IoU overlap to match detections to tracks.
    \item No appearance cue: frequent identity switches when players cross paths.
  \end{itemize}
\end{itemize}
\end{frame}

% ----- Final approach (video) ----------------------------------
\begin{frame}{Final Tracking: DeepSORT}
\begin{columns}[T]
  \begin{column}{0.55\textwidth}
    \textbf{DeepSORT} \cite{deepsort} adds appearance tracking to solve ID switching.
    \begin{itemize}
      \item \textbf{Visual Features:} Integrates an OSNet \cite{reid} appearance embedding.
      \item \textbf{Two-Stage Matching:} Prioritizes appearance similarity, falling back to overlap.
      \item \textbf{Appearance Gallery:} Maintains a history of embeddings for each track to compare against new detections.
      \item \textbf{Result:} Robust tracking through close interactions and partial occlusions.
    \end{itemize}
  \end{column}

% ----- Improvements --------------------------------------------
\begin{frame}{Tracking: Custom Improvements}
Specific enhancements made to the baseline DeepSORT pipeline:
\begin{itemize}
  \item \textbf{NSA Kalman Update:} Scales the measurement noise by detection confidence to drastically reduce bounding box jitter.
  \item \textbf{Low-Confidence Recovery:} Uses ByteTrack \cite{bytetrack} logic to track heavily occluded players via weak detections.
  \item \textbf{Track Resurrection:} Matches incoming detections against lost-track galleries to re-identify players re-entering the frame.
  \item \textbf{Coasting:} Emit tracks prediction when no detection is available, to avoid losing players during occlusions.
  \item \textbf{Label Resolution:} Smooths player classifications over time using a confidence-weighted majority vote.
\end{itemize}
\end{frame}
