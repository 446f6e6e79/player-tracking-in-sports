\section{Results}
\label{sec:results}
% ----- Detection and tracking findings -------------------------
\begin{frame}{Findings: Detection and Tracking}
\begin{columns}[T]
  \begin{column}{0.52\textwidth}
    \begin{itemize}
      \item Identities held well; recall is the bottleneck, not association.
      \item DetA $\approx$ AssA: errors are missed players, not bad matches.
      \item Recall and HOTA rank alike: detection drives tracking quality.
      \item The ball is the main bottleneck; stray balls cause spurious tracks.
    \end{itemize}
  \end{column}

% ----- 3D and trajectory findings ------------------------------
\begin{frame}{Findings: 3D and Trajectories}
\begin{columns}[T]
  \begin{column}{0.52\textwidth}
    \begin{itemize}
      \item Large trajectory errors driven by calibration bias.
      \item Similar ADE/FDE/MTE: a constant offset, not growing drift.
      \item Low fragment count: tracks stay continuous (three-camera redundancy).
      \item RMSE $\gg$ median: a few outlier frames dominate; errors are small relative to image scale.
    \end{itemize}
